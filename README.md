## 📖 About the Project
This is a single-page personal portfolio website (no framework) featuring Hero, About, Skills, Experience, Projects, Education, and Contact sections. The focus was on a distinctive visual design (custom cursor, typing animation, scroll reveal) built with clean code and zero external dependencies.

---

## ✨ Features
✅ Fully responsive design (mobile, tablet, desktop)  
✅ Custom cursor with a halo/glow effect  
✅ Typing animation in the Hero section  
✅ Scroll reveal animations for sections as the user scrolls  
✅ Timeline layout for work experience  
✅ Project grid with images, tech tags, and descriptions  
✅ No external libraries — pure HTML, CSS, and JS for maximum performance and control  
✅ Custom typography via Google Fonts (Space Grotesk + Inter)  
✅ Optimized images (WebP format) – faster load times and better Core Web Vitals
